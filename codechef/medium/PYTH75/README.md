## Problem

### Multiple Choice Question

What will be the output of this code?

```
a = 0
b = -10

if a >= b:
   print("a is greater or equal to b.")
if a == 0:
   print("a is 0.")
if a <= 5:
   print("a is not more than 5.")
print("Program ends")

```

## Solution

**Language:** C++  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-20T13:55:16.716Z

```cpp
score = int(input())
if score==100:
    print("perfect score")
elif score<100 and score>=80:
    print("almost perfect score")
elif score<80:
    print("nice try")
    
```
